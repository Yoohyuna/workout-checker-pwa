# Workout Check PWA

개인용 운동/습관 체크 앱입니다.

기능
- 월간 달력
- 1년 전체 보기
- 날짜별 색상 원 체크/해제
- 한 목적 안에서 여러 색상 중 선택해 체크
- 여러 목적을 상단 탭으로 구분
- 목적 이름 변경
- 새 목적 추가/삭제
- 현재 월로 최초 진입
- 월/연도 이동
- 다크모드 UI
- localStorage 기반 기록 저장
- PWA 홈 화면 설치 지원

## 가장 쉬운 실행 방법

로컬에서 테스트:
1. 폴더에서 터미널 실행
2. `python3 -m http.server 8080`
3. 브라우저에서 `http://localhost:8080`

아이폰에서 홈 화면 앱처럼 쓰려면 HTTPS 주소가 필요합니다.
GitHub Pages, Vercel, Netlify 등에 이 폴더를 그대로 배포한 뒤 Safari에서 열고
공유 > 홈 화면에 추가를 선택하면 됩니다.

주의:
- 기록은 현재 브라우저/기기의 localStorage에 저장됩니다.
- 브라우저 데이터 삭제 시 기록도 삭제될 수 있습니다.
